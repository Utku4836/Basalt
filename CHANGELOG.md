# Changelog

## 0.1.0 (2026-10-13)

First public release.

- Terminals in sessions, with split panes and tabs, restored on restart.
- Agents panel: 26 coding agents recognized from their processes, with their state
  read from the screen and from lifecycle hooks: working, waiting, done or idle.
- Profiles: the default uses your own setup; other profiles give each CLI its own
  home, settings and sign-ins.
- Installing missing commands from npm, PyPI and winget into Basalt's own folder.
- GPU terminal grid on Direct3D 12, PowerShell prompt with history suggestions,
  history search (Ctrl+R) and flag completion.
- A single `basalt.exe`, with ConPTY and the font (JetBrains Mono Nerd Font) bundled.
